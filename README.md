# Lucid PWA speech model

NVIDIA NeMo multilingual FastConformer hybrid transducer-CTC (transducer branch, int8), converted for sherpa-onnx by k2-fsa.
License: CC-BY-4.0 (NVIDIA). Source: https://github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models
The encoder is split into parts (GitHub rejects files over 100 MB); the Lucid PWA joins them.
